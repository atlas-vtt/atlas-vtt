# Pins

More control over note pins:

- **Pins that grow with the map**: a pin can keep its size on the map instead of on the screen, so a world map's pins shrink as you zoom out (the pin's context menu, or for the whole scene).
- **Zoom ranges**: a pin can show only from a zoom level in (small places) or only up to one (overview pins), so a large map stays readable at every zoom.
- **Pins shown to players**: pins are the GM's alone; a pin switched to "Show to players" also appears in the player view.
- **New notes from the pin search**: typing a name no note has offers "Create note"; the note is created in the folder set under Settings → Pins (default `atlas-vtt/collections/Default/notes`) and the pin links to it.
